# NetworkWalks – Week 3
## Project Module 1: Password Cracking with John the Ripper (JTR)

### Overview
This project was completed as part of my NetworkWalks Cybersecurity Internship. The objective was to understand how password-protected PDF files can be tested using John the Ripper.

### Tools Used
- John the Ripper Jumbo 1.9.0
- Johnny (GUI for John the Ripper)
- Windows
- PDF hash extraction utility

### Practical Work
- Configured John the Ripper with Johnny.
- Extracted password hashes from two practice PDF files.
- Performed password-cracking attacks using Johnny.
- Successfully recovered the passwords for both practice PDF files.
- Verified the results by opening the PDFs.

### Learning Outcomes
- Understood the basics of password hashing.
- Learned how John the Ripper works.
- Practiced using a graphical interface for password auditing.
- Gained hands-on experience with password-protected PDF files.
